UCM ({{ include "ucm.image" . }}) has been deployed as release "{{ .Release.Name }}".

1. Wait for the pod to become ready:

   kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ include "ucm.fullname" . }}

2. Reach the UI:
{{- if .Values.ingress.enabled }}

   https://{{ .Values.ingress.host }}/
{{- else }}

   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "ucm.fullname" . }} 8443:{{ .Values.service.httpsPort }}
   open https://localhost:8443/   (self-signed certificate)
{{- end }}

3. Log in:

   user: admin (or the name INITIAL_ADMIN_USERNAME sets in extraEnv)
{{- if not .Release.IsInstall }}
   password: unchanged, the existing administrator keeps its password (only the
   first start of a new installation reads the chart's initial password).
{{- else if eq (include "ucm.adminPasswordFromExtraEnv" .) "file" }}
   password: the one in the file INITIAL_ADMIN_PASSWORD_FILE names (extraEnv)
{{- else if eq (include "ucm.adminPasswordFromExtraEnv" .) "variable" }}
   password: the one INITIAL_ADMIN_PASSWORD provides (extraEnv)
{{- else if .Values.initialAdminPassword }}
   password: the value you set in initialAdminPassword
{{- else }}
   password: generated by the chart, read it with:

   kubectl -n {{ .Release.Namespace }} get secret {{ include "ucm.secretName" . }} \
     -o jsonpath='{.data.UCM_INITIAL_ADMIN_PASSWORD}' | base64 -d; echo
{{- end }}
{{- if and .Release.IsInstall (include "ucm.adminPasswordGenerated" .) }}
   It must be changed at first login; only the first start reads it.
{{- else if .Release.IsInstall }}
   Only the first start reads it: change it after login in Account > Password.
{{- end }}

IMPORTANT
{{- if .Values.ha.enabled }}
- HA mode: {{ .Values.replicaCount }} nodes on one PostgreSQL. UCM_SECRET_KEY and
  KEY_ENCRYPTION_KEY live in the "{{ include "ucm.secretName" . }}" Secret: back it up, losing
  KEY_ENCRYPTION_KEY makes every encrypted private key unrecoverable.
{{- if not .Values.persistence.data.existingClaim }}
- The data volume is an emptyDir per pod. Backup archives are kept in PostgreSQL,
  not on it: download the ones you keep out of the cluster, and back PostgreSQL
  up with its own tools.
{{- end }}
{{- if not .Values.redis.url }}
- No redis.url: sessions are per node. Set a cookie affinity on the ingress.
{{- end }}
{{- else }}
- This chart runs a SINGLE instance (replicaCount=1). The bundled scheduler is
  not HA-safe and the default SQLite DB is single-writer. Do not scale up.
- The "{{ include "ucm.etcPvcName" . }}" PVC holds /etc/ucm/master.key, which
  decrypts every private key in the database. It is annotated to survive a
  `helm uninstall`. Back it up and never delete it while data exists.
{{- if eq .Values.database.type "sqlite" }}
- Using the bundled SQLite database (data PVC). For an external PostgreSQL set
  database.type=postgresql and database.databaseUrl (or database.existingSecret).
{{- end }}
{{- end }}
